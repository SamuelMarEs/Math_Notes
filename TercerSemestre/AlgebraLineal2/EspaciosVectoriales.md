##### Definición:
El ejemplo básico de un espacio vectorial es $\mathbb{R}^{n}$ ($\mathbb{R}^{2}$ o $\mathbb{R}^{3}$). 
Formalmente, un espacio vectorial $V$ es un conjunto de *vectores* que satisface 8 axiomas sobre un *campo* $F$, que tiene una operación binaria (suma +) y una acción (producto escalar $\cdot$). Los 8 axiomas que debe cumplir son:
1. $\vec{x}+(\vec{y}+\vec{z})=(\vec{x}+\vec{y})+\vec{z}$ para todo $x,y,z\in V$.
2. Existe un vector $\vec{0}\in V$ tal que $\vec{0}+\vec{x}$ para todo $\vec{x}\in V$.
3. $\exists-\vec{x}\in V$ tal que $\vec{x}+(-\vec{x})=\vec{0}$ para todo $\vec{x}\in V$.
4. $\vec{x}+\vec{y}=\vec{y}+\vec{x}$ para todo $\vec{x},\vec{y}\in V$.
5. $\exists 1\in F$ tal que $1\cdot \vec{x}=\vec{x}$ para todo $\vec{x}\in V$.
6. $(a\cdot b)\cdot \vec{x}=a\cdot(b\cdot \vec{x})$ para todo $a,b\in F$ y $\vec{x}\in V$.
7. $(a+b)\cdot \vec{x}=a\cdot \vec{x}+b\cdot \vec{x}$ para todo $a,b\in F$ y $\vec{x}\in V$.
8. $a\cdot(\vec{x}+\vec{y})=a\cdot \vec{x}+a\cdot \vec{y}$ para todo $a \in F$ y $\vec{x},\vec{y}\in V$.
